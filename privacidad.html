Política de privacidad de LAIF

LAIF es un asistente personal de uso privado. Solo lo usa su propietario, con su propia cuenta de Google. No hay otros usuarios.

Qué datos usa

  • Gmail: leer, etiquetar y archivar el correo del propietario, y enviar las respuestas que él aprueba expresamente.
  • Google Calendar: leer la agenda del propietario y crear, mover o borrar los eventos que él aprueba expresamente.

Cómo los trata

  • Los datos se guardan en un servidor privado del propietario y solo se usan para darle a él las funciones del asistente.
  • Para contestar sus peticiones, algunos fragmentos se procesan con el proveedor del modelo de inteligencia artificial que usa el propietario, con su propia cuenta.
  • No se venden, no se usan para publicidad y no se comparten con nadie más.
  • Nada se envía ni se modifica fuera sin la aprobación explícita del propietario.

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso

El acceso se puede retirar en cualquier momento desde myaccount.google.com/permissions.
